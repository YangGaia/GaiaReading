# GaiaReading_Lucky

GaiaReading_Lucky 是一款面向 Windows 的绿色电子书阅读器，支持 EPUB、PDF、TXT、MOBI 和 AZW3。它把多格式阅读、章节级 AI 对话、划线笔记、阅读统计和桌面角色「久远寺有珠」放在同一个应用中。

当前稳定版本：**1.2.7**

[下载 Windows 便携版](https://github.com/lvlucky3641/GaiaReading_Lucky/releases/latest) · [源码仓库](https://github.com/lvlucky3641/GaiaReading_Lucky) · [MIT 许可证](LICENSE)

| 下载版本 | 音乐 | 使用方式 |
| --- | --- | --- |
| `GaiaReading_Lucky-1.2.7-Windows-x64-Full.exe` | 完整 59 首无损音乐 | 下载后直接运行，无需安装 |
| `GaiaReading_Lucky-1.2.7-Windows-x64-Lite.exe` | 1-01 主旋律、1-05 久远寺有珠、1-08 静希草十郎 | 功能相同，下载体积更小 |

便携版支持 Windows 10/11 x64，可放在任意可写的本地磁盘。首次启动会解压运行文件；书架、阅读进度、笔记和设置保存在 EXE 同级的 `数据` 文件夹。移动时将 EXE 和 `数据` 一起移动。两个版本使用相同的数据格式。

本项目基于 [YangGaia/GaiaReading](https://github.com/YangGaia/GaiaReading) v1.1.1 维护，改进批量导入稳定性、EPUB 搜索定位和开发环境检查。维护与验证方式见 [本地维护说明](docs/LOCAL_SETUP.md)，开发约定见 [开发说明](docs/DEVELOPMENT.md)，发布约定见 [GitHub 发布规则](docs/GITHUB_RELEASE.md)。

## 主要功能

### 阅读

- 支持 EPUB、PDF、TXT、MOBI、AZW3，保留书架、目录、进度和断点续读。
- 书架可通过“添加图书”选择文件夹、单个文件或一次多选文件；重复图书会自动跳过。
- EPUB、MOBI、AZW3 支持目录跳转；MOBI/AZW3 尾注可在应用内往返定位，TXT 可识别常见中英文章节标题。
- 阅读页左下角可随时打开目录；鼠标触碰阅读区最左侧时，目录会自动滑出并在离开后收回，也可在设置中单独关闭触边展开。
- 支持单页、双页、日间、护眼和夜间模式，并可调整字体、字号、行距与页边距。
- 日间、夜间和护眼配色仅作用于阅读界面；首页、书架、阅读目标和 AI 中心保持固定风格。设置侧栏使用独立的石墨灰配色，阅读配色选项只在阅读时显示。
- 日间、护眼和夜间主题均可切换高对比文字，分别使用纯黑、深棕黑和纯白增强可读性。
- EPUB、PDF、TXT、MOBI、AZW3 的双页间隙可在阅读设置中按 0、24、56、96px 四档即时调节。
- PDF 支持单页和双页阅读；双页可切换 `1–2` 或 `2–3` 配对，以适配封面、扉页和扫描页码差异。
- PDF 提供“适合页面”“适合宽度”和 10%～400% 手动缩放，可使用顶栏按钮或 `Ctrl + 鼠标滚轮`；普通滚轮先滚动当前跨页，到边缘后再翻页。
- EPUB、PDF、TXT、MOBI、AZW3 均支持书内全文搜索、结果列表、上下结果切换和正文定位高亮；扫描版 PDF 需先经过 OCR 生成文字层。
- 五种格式均可添加书签、三色划线和笔记。

### 批量导入

- 选择文件夹后异步扫描，扫描和导入期间显示当前文件、进度及已保存数量；长文件名会省略显示。
- 单本解析在独立进程中进行，超过 15 秒或进程异常退出会记为失败并继续处理后续文件。
- 每本成功后立即保存书架；取消导入会保留已经保存的结果，可以马上重新导入。保存失败时停止当前批次并提示，避免误报成功。
- Windows 路径按大小写及斜杠统一判断重复；大量重复文件也能取消。导入期间拦截重复任务，完成后分别统计成功、恢复、重复跳过和失败。
- MOBI/AZW3 导入只读取书架所需的信息；EPUB 对元数据和封面读取设上限，超大或损坏封面可以省略。超过 512 MiB 的 EPUB/MOBI/AZW3 使用文件名进入书架，实际阅读时再解析内容。

### AI 阅读助手

- 用户自行配置接口，支持 OpenAI、DeepSeek、兼容 OpenAI 格式的第三方服务和本地 Ollama。
- 可保存多套接口档案，分别管理 Base URL、API Key 和模型，并在 AI 中心切换。
- OpenAI 和自定义接口内置 `gpt-6-astra` 候选，模型 ID 原样保存和发送；实际可用模型由账号权限或接口服务商决定，原有档案不会被自动替换。
- 有章节时 AI 接收当前逻辑章节；无章节时接收当前页前 4 页和后 7 页（最多 12 页，边界截取），正文没有提供的信息会明确说明。
- 提供“总结本章”“人物关系”“伏笔”三个输入快捷键，点击后仅填入问题，由用户确认发送。
- 生成期间可以停止；输入新问题后可以中止旧请求并立即发送。
- “有珠吐槽”模仿《魔法使之夜》中久远寺有珠冷静、简短而略带讽刺的说话风格，通过桌宠气泡显示，不进入普通对话记录。

### 划词工具

- 选中文字后可染色、复制、让 AI 解读；染色摘录与笔记统一在“书签和笔记”的笔记页管理。
- “字典”会在应用内打开网易有道并直接查询选中文字。
- “全文搜索”在当前书中查找选中文字；“联网搜索”交给系统默认浏览器，可选择 Google、Bing、百度或自定义 HTTPS 搜索模板。

### 阅读记录与有珠

- 记录每日和每周阅读时长、目标完成度、连续阅读天数与年度读完书籍。
- 阅读目标页用 60 分钟计时表盘与完整数显展示今日累计阅读时长，支持 15 / 30 / 45 / 60 分钟目标；停留在统计页不累计阅读时间。
- 有珠支持点击、拖动、表情、哈欠、困倦、睡眠和梦话；低透明度时，鼠标碰到她会完全显现并唤醒。
- 右键有珠打开控制台，可调整尺寸、透明度、阅读页显示方式、自主休息和入睡速度；控制台与气泡互不遮挡。
- 内置 BGM 胶囊，支持播放、切歌、音量与状态记忆；阅读页超长曲名自动向左循环滚动，悬停或键盘聚焦时暂停，短曲名静止。
- 桌宠保持独立尺寸和拖动坐标，窗口放大不会同步放大有珠；书架以知更鸟、白色月牙、封面边框和阅读进度丰富展示。

## 本地运行

日常使用请下载上方的便携 EXE，无需安装 Node.js，启动时没有命令行窗口。保留其同级的 `数据` 文件夹即可保留阅读记录。

既有目录式版本继续通过原快捷方式或 `程序\GaiaReading_Lucky.exe` 启动；请保留完整 `程序` 文件夹。目录式版本按本地维护布局读取 `程序` 同级的 `数据`。

开发时先按下方说明配置环境、安装依赖，再执行 `npm start`；源码与 EXE 共用同一份 F 盘阅读数据。自动化验证必须使用独立的 F 盘临时档案。

系统要求：Windows 10/11 x64。

## AI 接口配置

| 类型 | Base URL 示例 | 模型示例 | 说明 |
| --- | --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` | `gpt-6-astra` 等账号可用 ID | 使用 OpenAI API Key |
| DeepSeek | `https://api.deepseek.com` | `deepseek-chat` | 使用 DeepSeek API Key |
| 第三方兼容接口 | 服务商提供的地址 | 服务商提供的模型 ID | 地址和 Key 均由服务商决定 |
| Ollama | `http://127.0.0.1:11434` | 本机已安装模型 | 完全本地运行，不需要 API Key |

Base URL 决定请求发送到哪里，API Key 用来向该地址证明身份，模型 ID 决定调用该服务中的哪个模型。三项必须与同一家服务的文档保持一致。自定义接口也提供 `gpt-6-astra` 候选；如果服务商采用其他命名，可直接填写它支持的 ID。

## 隐私与数据

- 书籍原文件、书架、进度、书签、笔记和阅读统计保存在本机，不上传到项目服务器。
- API Key 通过 Windows `safeStorage` 加密保存，只在 Electron 主进程中解密，不写入普通 JSON，也不会返回给页面。
- 使用云端 AI 时，当前章节或无章节书的 12 页范围正文直接发送到用户设置的 Base URL；远程地址必须使用 HTTPS，且请求禁止重定向。
- 项目不存在代收 API Key 或转发 AI 请求的开发者服务器。需要完全离线时，请使用本地 Ollama。
- 数据结构升级前会自动备份本地数据，最多保留最近五份备份。

## 从源码运行

需要 Windows 环境与 Node.js 22.12.0 或更新版本，推荐仍受支持的 LTS 版本。

```powershell
Set-Location 'F:\GaiaReading_Lucky' # 替换为源码所在的 F 盘目录
. ./scripts/dev-env.ps1
npm.cmd ci --include=dev
npm.cmd run doctor
npm.cmd start
```

Git 仓库不保存体积较大的 FLAC 音频。需要音乐、完整测试或重新打包时，先按 [音乐素材说明](assets/bgm/README.md) 恢复素材；个人阅读数据与 API 配置也不在仓库中。

源码包不包含 Node.js、npm、专用运行环境或 node_modules，请自行安装符合版本要求的 Node.js/npm。首次开发需联网执行 npm.cmd ci --include=dev；依赖完整时可跳过重复安装。便携 EXE 自带运行所需的 Electron，无需另装 Node.js。环境脚本只修改当前 PowerShell 进程，缓存与临时文件留在源码目录内的 .cache 和 .tmp。详细配置见 [开发说明](docs/DEVELOPMENT.md)。

```bash
npm run smoke:reader-ui # 阅读上下栏、音乐滚播、EPUB/PDF 与键盘鼠标交互验证
npm run smoke:epub-font # EPUB 固定字号、嵌套样式与排版回归验证
npm run dist        # 在 dist/win-unpacked 生成本地 Windows x64 目录式 EXE
npm run dist:portable # 分别生成 Full 和 Lite 两个单文件便携版
```

## 项目结构

```text
src/main.js          Electron 主进程、窗口、文件与本地状态
src/preload.js       安全的页面与主进程通信桥
src/renderer/        阅读器和应用界面
src/shared/          可独立测试的解析与业务逻辑
tests/               自动化测试和测试用电子书
assets/bgm/          音乐素材目录与恢复说明（FLAC 不提交到 GitHub）
```
