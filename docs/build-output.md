# 构建产物目录

`dist` 不纳入 Git。最新版绿色 exe 直接放在根目录，桌面同名快捷方式指向它。

```text
dist/
├── Gaia.Reading.1.1.1.exe   当前正式版，双击运行
├── archive/
│   └── Gaia.Reading.1.1.0.exe   上一正式版，供回退
├── previews/
│   └── 1.1.1/music-marquee.gif   曲名滚播预览
└── reports/
    └── 1.1.1/
        ├── release/       发行校验、启动与自动化测试记录
        ├── reader/        阅读栏和音乐滚播检查及截图
        ├── ui/            其他页面的回归检查及截图
        └── epub-font/     EPUB 字号回归检查及截图
```

## 保持目录整洁

- 日常测试通过各脚本的输出环境变量写入 `dist/reports/` 下对应的测试目录，预览放入 `dist/previews/`。
- 打包时可用 `npm run dist -- --config.directories.output=dist/_build --publish never` 将解包程序、构建缓存和生成日志放入临时目录。仅在用户明确要求生成 exe 时执行打包。
- 核验发行文件后，将新版 exe 放到 `dist` 根目录、上一版放入 `archive`，并更新桌面同名快捷方式的目标、工作目录和图标路径。
- 清理已完成构建的临时目录、过期日志和重复测试输出；保留当前发行版本的最终验证记录。不要将源代码、书籍或用户数据放入 `dist`。

## 本地验证

在 PowerShell 中运行：

```powershell
./scripts/verify-dist-layout.ps1
```

此检查只读取文件，核对目录结构、当前和回退 exe 的版本与发行校验值、验证记录、截图、滚播预览及桌面快捷方式。需要已构建的本地产物；源码刚克隆时无需执行。
