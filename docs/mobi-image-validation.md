# MOBI / AZW3 图片修复验证

## 问题与修复

- KF8 的 `kindle:embed` 和 `kindle:flow` 编号使用 32 进制；`mobi-parser 0.4.6` 分别按 36 进制和十进制读取，可能取到 `RESC`、`FLIS` 等非图片记录。兼容层在解析入口转换编号，保留原解析器的递归处理、缓存和清理机制。依赖固定为 0.4.6，升级时需要一起检查兼容层。
- KF8 返回的独立样式表原先没有传给阅读窗口。现在加载样式表并内联其中的图片，同时处理 SVG 内嵌图片、file URL、编码文件名及真实图片 MIME。
- 分页器原先只限制图片宽度。现在同时按单列宽度和页面可用高度等比限制图片；纯插图容器不再受正文缩进、行框和固定高度影响，行内小图保留尺寸。
- 图片超过原先 2.5 秒等待时间后仍能触发重排，并恢复文字或插图阅读位置；换章、关闭阅读器时清理监听。

## 可重复运行的验证

```powershell
npm test
npm run smoke:mobi-images
npm run smoke:mobi-images -- --book "本地样书的完整路径.mobi"
npm run smoke:epub-font
```

`tests/fixtures/mobi-image-fixture.js` 直接生成合法的 MOBI7 / KF8 PalmDB 文件，通过项目实际解析库和 IPC 打开，不模拟章节返回。测试书覆盖跨进制编号、独立 CSS、嵌套 SVG、长图、宽图和小图，不依赖私人样书或外部转换程序。

Electron 验证使用临时用户目录，不改动用户书库或阅读进度。它检查单页/双页、三种窗口尺寸、目录/设置面板、字号/边距/页间距变化、翻页、慢加载及阅读位置保持；同时从真实窗口截图取样，确认长图底部绿色标记确实绘制出来。

结果和预览在 `dist/previews/mobi-images/`。`--book` 会逐章通过生产 IPC 读取本地书籍，并让 Chromium 实际解码每个 img 资源。该目录及样书不会提交到 Git。

如需复核修复前的裁切，可将旧 `paginator.js` 保存到临时文件，用 `GAIA_MOBI_PAGINATOR_SOURCE` 指向该文件，并用 `GAIA_MOBI_IMAGE_OUTPUT` 指定单独输出目录。验证程序在隔离窗口中使用旧分页器，长图高度断言应失败，并留下 `initial-state.png` 供对照。
