# 翻页特效

翻页使用 20px、160ms、cubic-bezier(.2, .65, .3, 1) 的短距离横向滑入，起步迅速、短暂减速后停稳。下一页从右侧进入，上一页从左侧进入。取消原先 320ms 的半透明渐显，新页文字全程不透明，避免新旧文字叠加造成拖影。旧页纸面保留在下方托底，避免加载期间或移动边缘露出空白背景。

- TXT、EPUB、MOBI、AZW3 保留原来的翻页队列和页面准备流程。
- PDF 先完成画布、文字和图片层绘制，再在过渡回调内同步替换页面。绘制阶段不冻结动画帧，避免 PDF.js 等待 rAF 而卡住。
- 浏览器不支持过渡、过渡启动失败或截图被跳过时，补播相同 20px / 160ms / 缓动曲线的滑移。没有旧页快照时保持内容不透明；补播只影响视觉，不重复更新页码。
- 备用动画完成后才处理下一次排队输入。换书或离开阅读时取消过期动画，书籍边界不补播。
- 桌宠和控制台继续使用独立显示层，不参加书页的移动或淡入。减少动态效果设置继续生效。
