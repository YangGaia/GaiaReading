# 翻页与动画

点按立即翻一页；左右方向键按住约 200ms 后自动高速连翻，目标每秒 30 次，实际速度受内容加载和绘制耗时限制。普通点按和长按都保留 20px / 160ms 的短距离滑动。页码不等待动画结束；松开按键停止后续翻页，当前画面的滑动自然收尾。文字始终不透明，不叠加新旧文字。

- 删除 View Transition 截图、强制结束、备用补播及桌宠快照样式，只使用真实书页元素的 Web Animations 动画。
- 内容准备按输入顺序执行，动画的 `finished` 仅用于清理引用，不阻塞后续翻页。快速独立按键逐次保留。左右键的系统重复事件不另行翻页；PageUp/PageDown 维持原有操作。
- 长按使用一个 `requestAnimationFrame` 回调检查翻页时刻，任意时刻最多一个自动翻页正在加载。内容忙时不排队，耗时超出间隔也不追赶漏掉的次数。
- 连续输入共用正在播放的动画，不反复重置位置或缓动。PDF/跨章替换内容节点时沿用当前动画时间。长按高速模式同样播放动画，动画完成不控制按键响应。
- 松手使长按请求失效，尚未显示的 PDF/EPUB/MOBI/AZW3 页面不再提交；页码和进度与当前画面一起保留。首次点按独立处理，快速按下再松开不会丢掉这一页。
- 按下相反方向使旧长按失效，释放旧方向键不会停止新方向。失焦、隐藏窗口、离开阅读、打开设置、搜索或笔记编辑器都会停止连翻；正常进入阅读 iframe 的焦点切换不会误停。
- TXT/MOBI/AZW3 沿用分页及章节准备。MOBI/AZW3 的章节状态在 iframe 提交时同步更新。PDF 保留旧画布，待新画布、文字及图片层就绪后同步更新页码并替换。
- EPUB 章内使用原有翻页方法；跨章先在不可见位置完成章节及主题加载，保留旧 iframe，准备完成后同步替换。覆盖左右阅读方向和固定版式双页。
- EPUB 章节边界按真实滚动坐标判断，避免动画中的小数位让几何页码向下取整，造成快速反向翻页时提前跨章。
- 非 PDF 阅读区域裁切移动溢出；PDF 只移动纸面内部内容，外部尺寸及缩放滚动保持稳定，避免动画临时撑出滚动条。
- 桌宠不参与书页动画。换书/关闭阅读会清理旧动画，减少动态效果设置下不创建动画。

## 验证

```powershell
npm test
$env:GAIA_PAGE_TURN_OUTPUT = 'D:\Codex_project\Gaia_Reading\dist\page-hold-motion'
& node_modules/.bin/electron.cmd scripts/page-turn-smoke.js
```

运行验证使用临时数据，覆盖五种格式、三种阅读配色、单页/双页、正反翻页、延迟跨章/PDF 加载、窗口尺寸、桌宠透明度和拖动。额外构造 RTL 和固定版式 EPUB，检查跨章正确性及旧页保留。

键盘检查同时验证每秒约 16 次独立输入不丢失、不发送系统重复事件也能自动高速连翻、反向切换、松手后页码立即稳定，以及按下后 20ms 松开仍保留完整动画。主动挂起 PDF 绘制和 EPUB/MOBI/AZW3 跨章准备，检查松手后旧画面及进度保留、准备节点清理。单元测试使用受控时钟覆盖长按阈值、重复事件去重、加载期间松手、反向切换、边界和失焦。

实际动画逐帧记录位移、透明度、时间、阅读区尺寸和纸面像素，检查无空白/闪白、无瞬时滚动条以及动画帧无超过 50ms 的中断。测试主动禁用截图过渡，确保翻页完全独立于该接口。

输出目录保存报告和实际帧序列，包含普通松手、快速连按、长按与反向切换的画面；不会生成 exe。
