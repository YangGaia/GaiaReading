# 翻页与动画

按键驱动页面更新，书页内容独立播放 20px / 160ms 的短距离滑动。页码不等待动画结束；松开按键不会截断动画。文字始终不透明，不叠加新旧文字。

- 删除 View Transition 截图、强制结束、备用补播及桌宠快照样式，只使用真实书页元素的 Web Animations 动画。
- 内容准备按输入顺序执行，动画的 `finished` 仅用于清理引用，不阻塞后续翻页。快速独立按键逐次保留；系统长按重复在内容忙时丢弃，不加入积压队列，也不启动自动连翻定时器。
- 连续输入共用正在播放的动画，不反复重置位置或缓动。PDF/跨章替换内容节点时沿用当前动画时间。松手后当前动画自然收尾；已经开始的加载可以完成，但没有排队的长按补翻。
- TXT/MOBI/AZW3 沿用原来的分页及章节准备。PDF 保留旧画布，待新画布、文字及图片层就绪后同步替换。
- EPUB 章内使用原有翻页方法；跨章先在不可见位置完成章节及主题加载，保留旧 iframe，准备完成后同步替换。覆盖左右阅读方向和固定版式双页。
- 非 PDF 阅读区域裁切移动溢出；PDF 只移动纸面内部内容，外部尺寸及缩放滚动保持稳定，避免动画临时撑出滚动条。
- 桌宠不参与书页动画。换书/关闭阅读会清理旧动画，减少动态效果设置下不创建动画。

## 验证

```powershell
npm test
$env:GAIA_PAGE_TURN_OUTPUT = 'D:\Codex_project\Gaia_Reading\dist\page-live-motion'
& node_modules/.bin/electron.cmd scripts/page-turn-smoke.js
```

运行验证使用临时数据，覆盖五种格式、三种阅读配色、单页/双页、正反翻页、延迟跨章/PDF 加载、窗口尺寸、桌宠透明度和拖动。额外构造 RTL 和固定版式 EPUB，检查跨章正确性及旧页保留。

键盘检查同时验证每秒约 16 次独立输入不丢失、长按不积压、按下后 20ms 松开仍保留完整动画。实际动画逐帧记录位移、透明度、时间、阅读区尺寸和纸面像素，检查无空白/闪白、无瞬时滚动条以及动画帧无超过 50ms 的中断。测试主动禁用截图过渡，确保翻页完全独立于该接口。

输出目录保存报告和实际帧序列，包含普通松手、快速连按的画面；不会生成 exe。
