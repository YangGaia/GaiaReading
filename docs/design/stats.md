# 阅读札记 · 银灰时钟

阅读目标页延续首页、书架的石墨灰背景、银白文字和细线构图。布局由累计阅读时钟、今日读数与目标选择、有珠互动立绘组成；下方是每周阅读、连续阅读和年度已读书籍。

- 表盘用 SVG 实际绘制，包含 60 个刻度、时分秒针、轴心和目标外圈。缩放调整绘制尺寸，不缩放整张合成图层。
- 指针对应今日累计阅读时长，数字保留完整小时和秒。12 小时之后模拟指针循环，数字读数继续累计；外圈完成度上限为 100%。停留在统计页不计入阅读时间。
- 每日目标延用 15 / 30 / 45 / 60 分钟与原存储规则。目标按钮支持悬停高光、轻抬升、按下阴影及键盘焦点。
- 每周柱状图在悬停或聚焦时显示日期及精确时长；已读书籍展示完成日期。未变化的内容保留 DOM 节点，不打断聚焦和悬停。
- 字体与首页共享本地 Noto Sans SC 和随软件分发的 Cormorant Garamond。有珠使用原统计页整张立绘及原眨眼、哈欠、睡眠动作。
- 常用尺寸保持三栏构图；窄窗口逐步换行，所有内容通过纵向滚动访问。音乐胶囊沿用现有缩放规则。
- 样式限定在 `#stats-view`，不改阅读配色、翻页、桌宠定位、首页或书架逻辑。无第三方推广署名，不生成 exe。

## 验证


单独验收目标页时，设置 `$env:GAIA_UI_STATS_ONLY = '1'` 后执行 UI 验证；全量验证前移除该变量。

验证使用临时用户数据，覆盖 800×600、1100×760、1600×1000、宽屏、竖向窗口、窄窗口与 125% 缩放；检查真实计时、零值、目标完成及超一小时状态、文本对比度、字体加载、控件无遮挡、焦点持久、三种阅读主题隔离与减少动态效果设置。截图和报告位于指定输出目录。
