# 阅读页上下栏

上下栏使用新版书架和设置页的石墨灰、银白文字及细线图标。正文的日间、护眼、夜间配色继续独立生效。

- `reader-chrome.css` 只匹配 `#reader-view` 直属的上下栏；控件沿用原 ID、事件和功能。
- 按钮高 36px、圆角 7px，提供悬停、按下、键盘焦点、面板打开和禁用状态。对话按钮取消循环扫光；有珠保留图标点缀色和加载文字。
- 目录在左，翻页按钮成组居中，进度在右；进度线为 2px。
- 1040px 以下收起部分按钮文字，保留图标、工具提示和可访问名称。PDF 在 1100px 以下、其他格式在 960px 以下将音乐和其他操作移到第二行，PDF 缩放与配对保留在书名旁。
- 阅读音乐胶囊为 396×56px，曲名区域约 158px，完整显示四首内置曲名。封面始终保持 32px 正方形，播放按钮保持 28px；紧凑的播放组与音量区域分开。曲名静态显示，不增加滚动动画。阅读设置打开后沿用相同胶囊尺寸及原有避让动画；首页、书架等页面保持原尺寸。

## 验证

运行 `npm test`、`npm run smoke:reader-ui`、`npm run smoke:epub-font` 及 `npm run smoke:ui`。

阅读栏专项使用临时图书和偏好，验证真实 Electron 渲染及鼠标／键盘输入，覆盖 800–1600px、三种正文主题、EPUB／PDF 单双页、长标题、控件命中区域、对比度、翻页、目录、搜索、音乐、设置和有珠忙碌状态。有珠响应在 IPC 边界模拟，不调用外部 AI。

专项截图与报告位于 `dist/reader-ui-smoke/`；普通改动不生成 exe。
