# Gaia Reading 首页静态预览

本目录保留独立的首页视觉设计稿。新版已经接入正式软件：在项目根目录执行 `npm start`，重启开发版窗口即可查看。生产页面使用 `src/renderer/home.css`，首页按钮连接原有操作，音乐播放器和桌宠使用真实实例。

浏览器直接打开本目录的 `index.html` 仍可查看静态设计参考。该参考页不会操作软件数据。

## 正式软件的等比例缩放

正式首页以 1100×760 为构图基准，使用 `min(可用宽度 / 1100, 可用高度 / 760)` 计算统一比例。标题、入口、原画、框线和播放器保持相同构图，尺寸变化时不切换分栏。长宽比不一致时内容居中，剩余区域延展石墨色背景。桌宠独立于这个比例。

`src/renderer/home-layout.js` 通过 ResizeObserver 更新 `--home-unit`。字号、控件、间距和图标都用这个长度计算最终 CSS 尺寸，由浏览器按最终尺寸绘制；首页容器不使用 transform/zoom 放大合成图层，播放器不使用 backdrop-filter。居中位置对齐设备像素，避免整个界面落在半个设备像素上。

桌宠大小只由原来的尺寸设置决定，不随首页变大或变小。鼠标拖动、键盘移动、位置比例保存都使用整个软件窗口，包括居中内容两侧的留白；仅窗口的真正边缘限制移动。隐藏后再显示、页面切换和窗口缩放均保留用户设置。

隐藏的台词气泡使用 `display: none`，淡出时禁用命中，避免透明气泡继续拦截底下的控件。

运行 `npm start` 可验收正式效果。本目录静态稿保留此前的响应式排版，仅供视觉参考，不代表当前软件的缩放行为。

## 本轮设计

- 主图及音乐缩略图引用正式首页使用的 `src/renderer/images/1.jpg`。加载页的 `2.jpeg` 不再用于此预览。
- 原图文件保持不变；`assets/alice-matte.png` 只去除与图片外边缘相连的白色底图，保留人物、肤色和原画中的青灰矩形。没有椭圆渐隐、人物压暗或拉伸。
- 顶部横线连接标识与音乐播放器，竖线组织左右分区；人物周围的矩形框线在帽檐和衣服伸出的位置断开。SVG 框线保持固定描边宽度。
- 保留石墨灰背景、银白文字和顶部音乐控件材质。产品名与主操作对齐，次级入口采用轻量按钮；设置与桌宠分别放在页脚两端。
- 使用本机安装的 **Noto Sans SC**，标题 36px / 500 字重，入口文字 14px。专用验证通过 Chromium 实际渲染字体接口检查字体回退。

## 静态设计稿的响应式行为

宽窗口为左右双栏，整体最大宽度 1280px。间距随窗口连续变化，人物同时受可用宽度和高度约束，保持正方形原图比例。软件当前的最小窗口 800×600 以及主要桌面尺寸完整容纳内容。

可用 CSS 宽度不超过 740px 时切换上下布局；不超过 540px 时音乐播放器独占一行；极窄布局把音量调节另起一行。所有播放控件、音量与四个入口都保留。空间不足时可以纵向滚动，无横向溢出，键盘导航会将焦点入口带入视野。

## 预览边界与正式接入

四个入口和音乐播放器只展示交互状态；音量滑杆可以拖动，但不连接实际音频。页面不加载 JavaScript、应用 preload 或业务模块，不访问用户数据，不请求网络素材。页脚署名链接由用户点击后在新标签页打开。

正式首页在 `src/renderer/index.html` 中保留原有四个入口 ID；统一缩放保持固定的桌宠预留区域，不因桌宠开关改变主图与按钮构图。播放器使用首页挂载位置和图标状态，播放、切歌、音量及保存机制沿用原实现。轮廓蒙版位于 `src/renderer/images/home/alice-matte.png`，生产页面不依赖本预览目录。

正式软件验证使用临时用户目录，可执行 `npm run smoke:ui`；设置环境变量 `GAIA_UI_HOME_ONLY=1` 可只运行首页检查。完整验证包含首页缩放与键盘操作、真实音乐控制、导入与导航，以及书架、阅读目标和阅读页的回归检查。`GAIA_UI_OUTPUT_DIR` 可指定截图与报告目录。

等比例验证逐项比对 16 个首页元素的位置与尺寸，覆盖 40 个连续窗口尺寸、宽屏与窄长窗口、原生最大化与全屏、125%/150%/200% 页面缩放。检查实际计算字号随比例变化，且文字祖先没有 transform、zoom 或滤镜放大，再通过原始像素截图目视检查播放器文字与图标。

桌宠专项在 800×600、1600×1000、2560×1080、800×1000 窗口中分别测试 75%、100%、150% 三档大小，真实拖到四角并核对窗口边界、指针释放和保存的位置比例。页面缩放验收时通过真实拖动将桌宠放到中间空隙，关闭临时台词气泡后检查首页控件；桌宠保持可见。另行验证键盘移动、真实音乐控制、设置过渡、页面导航及隐藏后重新显示。

```powershell
$env:GAIA_UI_OUTPUT_DIR = "$PWD\dist\home-scale-full"
npm run smoke:ui
```

正式截图命名为 `home-runtime-800x600.png`、`home-runtime-1100x760.png`、`home-runtime-1600x1000.png` 等；全屏截图为 `home-runtime-fullscreen.png`，播放器细节截图为 `home-music-fullscreen-native-pixels.png`，验证结果为同目录下的 `report.json`。验证只启动开发版，不执行打包。

书架、阅读目标页、阅读界面及业务数据不在本轮修改范围；目标页后续应恢复并保留原有时钟式设计。不生成 exe。
