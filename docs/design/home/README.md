# Gaia Reading 首页静态预览

这是一份独立的首页视觉设计稿，供验收字体、人物构图与控件材质。直接在浏览器中打开本目录的 `index.html`，即可查看悬停、键盘焦点和按下状态。

- 采用本机的 **Noto Sans SC** 可变字体；未安装该字体时浏览器会回退，专用验证会将字体回退报告为失败。
- 主图引用现有灰白有珠原画，桌宠引用现有完整人物图片。原图没有修改，人物过渡由 CSS 遮罩完成。
- 四个入口和音乐播放器只有视觉状态，未接入图书导入、AI、设置或音频。滑杆可拖动以查看控件状态，不改变实际音量。
- 页面不加载任何 JavaScript、应用 preload 或业务模块，不访问用户数据，也不请求网络素材。署名链接由用户点击时在新标签页打开。
- 正式软件的首页、书架、阅读目标页和阅读界面均不受这份预览影响。

## 验证与截图

从项目根目录执行：

```powershell
.\node_modules\.bin\electron.cmd scripts/home-preview-smoke.js
npm test
```

预览验证使用独立的临时用户目录和无 preload 的 Electron 窗口，检查实际渲染字体、图片加载、正文对比度、控件遮挡、键盘焦点、悬停/按下反馈和减少动态效果设置。

验证结果保存在 `dist/home-preview/report.json`。截图保存在同一目录：

- `home-1100x760.png`：主要验收尺寸。
- `home-800x600.png`、`home-1600x1000.png`：小窗口与大窗口适配。
- `home-hover-1100x760.png`、`home-pressed-1100x760.png`、`home-focus-1100x760.png`：主入口的交互状态。

自动对比度检查按实际计算文字颜色与背景色/渐变停靠点估算；人物遮罩与整体观感仍需结合截图目视验收。截图和报告为可重新生成的验证产物，不属于发布资源。

本轮仅供首页视觉验收。首页认可后再独立接入；书架和阅读目标页另行处理，目标页应恢复并保留原有时钟式设计。本轮不打包 exe。
