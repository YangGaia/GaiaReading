# 阅读助手行为验收

普通问答使用当前章节中截至当前显示页可获取的正文；PDF 使用当前显示页。整章总结须明确选择“含未读”，范围仅对本次请求有效。通用知识与分析可以超出正文，书中剧情事实须与推测和背景知识区分。

## 自动验证

运行 `npm test` 和 `npm run smoke:ai-reading`。

专项 smoke 使用独立临时用户目录和本地模拟接口，不读取用户 API Key、不调用云端模型。它验证真实阅读器、界面、IPC 与最终网络请求中的正文和历史范围，覆盖 EPUB、TXT、MOBI、AZW3、PDF、超长单段落、同一文档中的小章边界、简繁转换、双页、窄窗口、整章授权重置、回翻及无正文页面。截图中的回复明确标注为本地模拟，不代表真实模型的回答质量。

## 真实模型验收样例

使用自己的接口，在一本读到中途的书中逐项提问。下列标准用于人工评价实际模型表现，自动测试不替代这一评估。

| 问题 | 应有表现 |
| --- | --- |
| “认知失调是什么意思？能联系这段文字解释吗？” | 解释通用概念，能联系细节时分析，不能以“正文未提供”为由拒绝概念解释。 |
| “他为什么沉默？还有其他合理解释吗？” | 用已提供的言行支持分析，区分解读与已知事实。 |
| “这个细节是伏笔吗？大胆推测一下。” | 可以提出猜想，不确认后文兑现，不暗示后面是否重要。 |
| “介绍这个时代的文化背景，不要剧透。” | 可以介绍文化制度，避免以历史人物真实结局或情节对比泄露本书后文。 |
| “凶手是谁？” | 若当前正文没有揭晓，不直接说出后文答案；可讨论已有线索，询问是否允许剧透。 |
| “允许剧透，只告诉我这个人物的结局。” | 仅在指定范围展开，不确定作品或版本时说明不确定。 |
| 上一问后再问“分析当前这段的比喻” | 回到默认边界，不延续先前的剧透授权。 |
| “先不谈这本书，解释一下叙事视角。” | 正常回答书外知识问题。 |
| 阅读整章总结后取消整章范围，再提普通问题 | 新请求中不含整章回答，不继续引用未读信息。 |

模型本身的知识、指令遵循能力及服务商行为仍会影响答案。程序会限制传入正文并明确回答规则，但不能承诺任意第三方模型绝不泄露其训练中已有的剧情知识。
