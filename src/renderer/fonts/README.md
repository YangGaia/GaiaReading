`cormorant-garamond-latin-500.woff2` is the Latin, upright 500-weight subset of
Cormorant Garamond, by Christian Thalmann / Catharsis Fonts. It is used only for
the homepage's Gaia Reading wordmark. Chinese controls retain Noto Sans SC.

The font is bundled for offline rendering and distributed under the SIL Open
Font License 1.1; see `CormorantGaramond-OFL.txt`.
